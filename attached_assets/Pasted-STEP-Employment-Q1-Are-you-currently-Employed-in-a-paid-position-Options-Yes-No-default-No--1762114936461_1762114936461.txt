STEP: Employment
Q1. Are you currently Employed in a paid position?

Options: Yes, No (default: No)

If Yes → show Current Job (inline)

Employer/Organization (text, required)

Position/Job Title (text, required)

Country (dropdown, required)

Start Date (DD/MM/YYYY, required)

Still working here? (Yes/No, required)

If No → End Date (DD/MM/YYYY, required)

Employment Type (dropdown: Full-time, Part-time, Contract, Self-Employed)

Address (text, optional)

Q2. Employment History (last 5 years)

Control: Repeater table with columns: Date From, Date To, Status, Position, Country + Edit/Remove + Add

Employment History — Add/Edit modal

Date From (DD/MM/YYYY, required)

Date To (leave blank if ongoing) (DD/MM/YYYY, optional)

Status (dropdown, required):
Employed, Student, Retired, Self-Employed, Unemployed, Work Experience/Internships, Unpaid Employment/Volunteer

Position / Occupation (text, required if Status = Employed or Self-Employed)

Employer/Organization (text, optional)

Country (dropdown, required)

City/Town (text, optional)

Duties/Notes (textarea, optional)

Validation

DateFrom ≤ DateTo when DateTo present.

At least one history row required if Q1 = No (not currently employed).

STEP: Education
Q1. Have you ever undertaken or enrolled in any studies or training at secondary level or above?

(Includes high school, college/vocational, university, research/thesis, specialised training, skill/trade qualifications.)

Options: Yes, No

If Yes → Education History (Repeater)

Columns: Institution, Qualification, Field, From, To, Country + Edit/Remove + Add

Education — Add/Edit modal

Institution Name (text, required)

Country (dropdown, required)

Qualification/Level (dropdown: Secondary, Diploma/Certificate, Bachelor’s, Master’s, Doctorate/PhD, Other, required)

Field of Study (text, required)

Date From (DD/MM/YYYY, required)

Date To (DD/MM/YYYY, required)

Study Mode (dropdown: Full-time, Part-time, required)

Graduated/Completed? (Yes/No, required)

Document/Certificate Number (text, optional)

Validation

From ≤ To.

At least one row when Q1 = Yes.
