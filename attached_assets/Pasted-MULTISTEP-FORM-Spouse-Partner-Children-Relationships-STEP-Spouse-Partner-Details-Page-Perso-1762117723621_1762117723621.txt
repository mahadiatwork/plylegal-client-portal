MULTISTEP FORM — Spouse/Partner, Children & Relationships
STEP: Spouse/Partner → Details
Page: Personal Details
Context

This step captures information about the applicant’s spouse or partner.
It should appear only if the applicant’s marital status is Married or De Facto.

Validation & UX Rules

Conditional display:

Show “Spouse/Partner” section only if marital status = Married or De Facto.

Show “Children” only if Q1 = Yes.

Show “Other Personal Details” if spouse has name variations.

Repeaters:

Each Add/Edit modal validates required fields before adding to list.

Each list supports Edit and Remove.

Data integrity:

Ensure all modal data commits to the parent step form before “Save” or “Continue”.

Validate all required date fields (Date From ≤ Date To when applicable).

Navigation buttons:

Previous → return to prior step

Save → triggers “Draft Save” (must persist form state)

Continue → validate → move to next step
