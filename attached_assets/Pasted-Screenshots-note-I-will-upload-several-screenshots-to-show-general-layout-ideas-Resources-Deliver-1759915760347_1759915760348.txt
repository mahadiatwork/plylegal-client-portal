🔧 Critical Bug Fix for Questionnaire (do NOT auto-advance)

Problem: Current questionnaire jumps to next page after adding data (e.g., saving a repeater row or submitting an inner form).
Required fix: Never change route automatically. Only navigate when:

User clicks Next/Continue in the sticky footer or bottom buttons, or

User clicks a link in the sidebar / contextual tabs.

Implementation rules:

Forms on each page must NOT auto-submit on Enter.

Add onKeyDown={(e) => e.key === 'Enter' && e.preventDefault()} to top-level <form> unless the Enter key is pressed inside a dialog that is explicitly meant to submit a row.

Buttons that are not the Next/Continue action must be type="button".

Examples: “Add Row”, “Save Row”, “Save Draft”, “Previous”, “Cancel”, “Close Dialog”.

Row dialogs (Add/Edit) in repeaters must close and leave the user on the same page.

On submit: update RHF state + localStorage, show a toast (“Saved”), do not call router.push.

Next/Continue should be the only control that validates current page and navigates:

const onContinue = form.handleSubmit((values) => {
  saveDraft(merge(values));          // localStorage + POST /api/intake/save
  router.push(nextHref);             // navigate ONLY here
}, (errors) => {
  setShowErrorSummary(true);         // stay on page, focus first error
  // DO NOT navigate
});


Previous navigates back without validation (and without losing unsaved values):

const onPrev = () => {
  saveDraft(merge(form.getValues()));
  router.push(prevHref);
};


Autosave (every 10s and on route change) must not navigate; it only persists.
